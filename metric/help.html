    Want to know how to use Ductulator.com?
    1. Enter duct sizing criteria:
         - Maximum air velocity
         - Maximum air pressure drop in Pascal per Meter
    2. Enter design airflow in Liters per second.
    3. Use any of the duct sizes shown.    
    4. If desired, adjust duct size by clicking up or down arrow.

    
    Need to add up multiple airflow values?
    - Press enter after placing cursor in the Airflow Quantity box. Start typing numbers with "+" sign then press "Enter". 
    - Website will calculate total airflow and type it in the Airflow Quantity box.
